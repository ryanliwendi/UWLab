# Asset provenance

`vx300s_aloha.urdf` is a converted ViperX 300s arm with ALOHA gripper visuals/collisions and estimated actuator configuration. It is not a calibrated hardware model.

- Arm meshes: Interbotix/interbotix_ros_manipulators, commit `0bb2b0e6d0e619bff02cf74dbd5af5681dcf80c9`. License: `licenses/INTERBOTIX.txt`.
- Gripper/finger/camera-mount meshes: google-deepmind/mujoco_menagerie, ALOHA assets. Original downloaded content is pinned by SHA-256 in `mesh-manifest.json`; upstream main URLs are mutable, so the fetcher fails closed on any content change. License: `licenses/MENAGERIE.txt`.
- Plate and scene geometry are generated by the included scripts. Wood texture is generated locally from an existing dataset frame; it is not included here.
